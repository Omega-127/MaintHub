API

REST for the plant system

JWT auth, department-scoped queries, dashboard aggregates, and maintenance history — Flask behind the Flutter client.

POST /api/auth/login Issue JWT for technician or admin
GET /api/dashboard/ Totals, overdue, due-soon KPIs
GET /api/machines/ Registry filtered by department role
GET /api/machines/export/excel Export styled Excel maintenance schedules
GET /api/notifications/ In-app alerts and debounced sync
POST /api/maintenance/{id}/complete Log service; advance next date

Setup

From clone to first login

MySQL (or SQLite locally), Flask API, Flutter app pointed at your host.

  1. Database

    Bring up MySQL with docker-compose up -d mysql, or use the SQLite fallback for a quick local pass.

  2. Backend

    Install Python deps in mainthub-backend, set env for the DB, run the Flask app. Schema migrates on start.

  3. Mobile app

    Point the Flutter client at your API base URL, then build or run on Android. Detail lives in the setup guide.
